# Assumption ledger

Every inference made while building Phase 2 that the brief did not state. One line
each: what was assumed, why, and what to check. Delete this file once confirmed.

ASSUMPTION: `@concordium/x402` does not exist; the package is `@x402/concordium` 2.32.0 | REASON: npm answered 404 for `@concordium/x402`; `npm search` and the registry metadata show `@x402/concordium` published by x402-foundation, depending on `@x402/core` and `@concordium/web-sdk`, exporting Client, Server and Facilitator | CONFIRM: that this is the package the workshop meant, before wiring the Node bridge.

ASSUMPTION: finality is about 10 seconds, not 2 to 4 | REASON: the package README states ~10s deterministic finality and defaults its finalisation timeout to 60s; the package is the primary source | CONFIRM: which number the judges expect to hear.

ASSUMPTION: `demo.veriox.io` exposes no API | REASON: the page served on 21 Nov 2026 is an age-gated storefront ("The Cellar") with a "Reset verification" control and no fetch calls or documented endpoints | CONFIRM: the integration guide's real request and status paths, which are therefore configuration and not constants.

ASSUMPTION: the agent registry contract is `12802,0` on testnet | REASON: the workshop corrections state this address is verified regardless of the CIS-804/CIS-8004 naming question | CONFIRM: that it is the agent registry and not a different contract.

ASSUMPTION: audit anchoring uses nonce + hash, anchored with `registerData` | REASON: the workshop's GDPR-safe Article 12 pattern; only the hash ever leaves the process, so deleting the row makes the on-chain hash unmatchable | CONFIRM: the anchor cadence and who pays for those transactions.

ASSUMPTION: payment requirements are built by the packaged Server and verified by the packaged Facilitator, reached through a small Node bridge | REASON: the package is TypeScript and the backend is Python; writing a facilitator is explicitly out of scope | CONFIRM: whether the bridge runs in the same deployment or as a separate service.

ASSUMPTION: the nine verification rules are enforced in two places: eight locally, the signature by the facilitator | REASON: our side holds no verifier key, and claiming to check a signature without one would be the false assurance this project exists to avoid | CONFIRM: that the facilitator is trusted to be the only signature check.

ASSUMPTION: the demo neighbourhood is Yaba, Lagos, centred on 6.5095, 3.3711 | REASON: the previous project is Lagos-based and the brief asks for one neighbourhood | CONFIRM: that a Lagos demo reads correctly to the judges.

ASSUMPTION: the seeded demo person is `judge.demo@proxid.local` with a fixed password | REASON: the demo needs a session the seed can create without OAuth | CONFIRM: that a fixed demo password is acceptable, given the account is marked `is_demo` in its row and the route is flag-gated.

ASSUMPTION: demo chain-shaped values are `demo-` prefixed strings | REASON: they cannot parse as base58 account addresses or 64-character hashes, so a script or a reader cannot mistake them for chain data | CONFIRM: that no demo string is ever rendered as if it were an address.

ASSUMPTION: the rate limiter is in-process | REASON: a single-instance deployment does not need a shared counter, and the interface does not change when Redis arrives | CONFIRM: the worker count, because the effective limit is the configured one times the workers.

ASSUMPTION: the frontend uses React 18 with react-leaflet 4 | REASON: the brief specifies React 18, and react-leaflet 5 requires React 19 | CONFIRM: that React 18 is the intended version.

ASSUMPTION: Tailwind 3.4 with a config file rather than Tailwind 4 CSS-first | REASON: the design tokens are CSS custom properties mapped into Tailwind's colour scale, which is clearer with a config | CONFIRM: that the version split from the previous project does not matter.

ASSUMPTION: sessions are JWTs backed by a `user_sessions` row | REASON: the house standard requires logout to invalidate server-side, and a stateless token cannot | CONFIRM: the session TTL (7 days).
